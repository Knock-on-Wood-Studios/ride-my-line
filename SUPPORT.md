# Ride My Line support

Gameplay bugs and accessibility problems should be filed at:

<https://github.com/Knock-on-Wood-Studios/ride-my-line/issues/new>

Include the browser, device type, yard number, expected behavior, actual behavior, and reproducible steps. Do not include private information in a public issue.

Security and privacy vulnerabilities must be submitted privately at:

<https://github.com/Knock-on-Wood-Studios/ride-my-line/security/advisories/new>

The deployed, player-facing version is `support.html`.
